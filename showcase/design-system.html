设计原则

DO · 紧凑信息密度
行高 20px、字号 13px、1px 实线分隔。对标 VS Code / JetBrains / DaVinci。一屏内放得下 30+ 条记录是常态。
DON'T · 不模仿 iOS
大圆角、毛玻璃、超大留白、阴影模糊都不属于工业桌面。半径上限 6px，阴影只为弹层服务。
DO · 状态优先
颜色服务于状态读取（成功 / 警告 / 危险 / 录制），而不是品牌装饰。Accent 用在可点击的关键焦点上。
DON'T · 不堆装饰元素
不使用渐变背景、装饰性插画、emoji 状态。LED 圆点 + 等宽数字 + 1px 描边足以承担一切语义。

11颜色系统surface · text · accent · semantic

表面分 5 层（base → subtle → surface → hover → active），每层 ΔL ≈ 4–8。文本 3 级配套对应表面层级。Accent 与 4 种状态色独立，确保「色相不夺主、状态读得准」。

12排版2-stack · 6-step

两套字体栈：--font-stack 用于 UI 文本，--mono-stack 用于代码、数值、路径、token 名。字号阶梯只有 6 档，最大 24px——这是桌面工具，不是营销页。

15阴影与焦点double-layer + 1px ring

阴影格式：<depth shadow>, 0 0 0 1px <outline> 双层结构——既给深度感又保证扁平背景上的轮廓识别。

20按钮7 variants · 3 sizes · icon / loading

扁平设计:实色填充 + 1px 边框,不用高光 / 斜面 / 投影。层级只靠填充色 + 边框 + 文字色表达 —— Primary 实色 accent、Default 中性面、Ghost 无边框。交互态仅切换表面色,简洁克制。

DO · 一个 primary
任何对话框 / 表单底栏只允许 1 个 btn--primary，承担「主要意图」。其余动作用 default / ghost。affix 图标用 .btn-affix 降低不透明度,让文字主导。

danger 红只用于「删除 / 解除 / 强制中断」类不可逆动作。确认对话框的「确定」用 primary。loading 态用 data-loading="true",宽度不跳动。

39窗口控件minimize · maximize · restore · close · custom

桌面窗口的标准三联控件 —— 最小化 / 最大化(还原) / 关闭 —— 全部使用 SVG 线性图标,绝不用文字字符。按钮 26×22 紧凑型,关闭是唯一的破坏性控件,hover 时红色填充。自定义工具控件(置顶 / 主题 / 设置 / 帮助)排在标准三联左侧,色阶更弱。两套窗框范式并存:macOS 红绿灯 + Windows/Linux 方形按钮。
