移动端 App UI

工业级桌面规范的移动孪生。沿用同一支强调蓝与语义结构,但为触控、单手、通透重做基底:更亮的分组背景、更大的触控目标、更柔的圆角、以及把桌面的 hover 心智整体迁移到 press。通用跨平台,不照搬 HIG / Material。

Body 17px / 系统字体栈 Touch ≥44px · 默认 48px Radius 8–22px 柔角 Base 通透白 + 浅灰分组 Mode Light(深色预留)

00.1 五条移动原则 principles

  • 触控优先没有 hover。所有桌面靠悬停传达的反馈(边框加强、底色预览)迁移到 press;静止态即最终态,不依赖鼠标移入才"显形"。
  • 够大可点命中区 ≥44px,舒适默认 48px,主操作 56px。视觉可以小,但热区不能小。
  • 通透分层白色内容卡浮在浅灰分组底上,层级靠柔阴影 + 发丝线,而非桌面那种逐级加深的灰 chrome。
  • 单手友好主操作落在拇指可达区(屏幕下半);破坏性/次要动作上移。导航在底部 Tab 栏。
  • 克制用蓝强调蓝照搬桌面铁律——只在元素自身的选中 / 开启 / 当前态出现;press 默认中性。

00.2 强调色铁律 · 移动版 accent discipline

与 CLAUDE.md 同源:accent 是"在预览/表达该元素自己的值"。移动端按触控重新落位——

✓ 合法的 accent
开关 ON、checkbox/radio 选中、选中的列表行(accent tint 底 + 蓝标题 + 勾)、当前 Tab(蓝图标+标签)、选中 filter chip、输入框聚焦环、主按钮(填充蓝,press 转深蓝=预览自身值)、链接/文字按钮。
✗ 禁止 accent
普通列表行 press 变蓝(应中性灰)、outline / 中性按钮 press 出现蓝边或蓝底、分段控件选中段变蓝(应为白色浮起药丸)、未选中 Tab、sheet 抓手、普通图标 press。
vs desktop继承:强调蓝 #1a6fe0、语义状态色、accent 铁律、token 分层心智。 改造:密度↓、触控目标↑、圆角↑、hover→press、灰 chrome → 通透分组底、等宽数据字 → 纯系统字体。

20 交互模型 · hover→press 迁移 touch idioms

桌面规范里大量状态心智建立在 hover 上。触屏没有 hover——下面是逐条迁移与新增的手势约定。

状态迁移表

桌面(鼠标)移动(触控)表现
hover 中性加深— 取消静止态即最终态,不存在"移入才显形"
hover 边框加强press按下时中性底色加深(--m-press / bg-tertiary)
:active 下沉阴影scale(0.97)按钮/卡片整体轻微缩放,替代 inset 下沉
focus ring(键盘)仅输入聚焦移动焦点环只在文本框激活(键盘弹起)时出现
selected = accentselected = accent不变:选中/开启/当前仍是蓝(铁律照搬)

按下反馈 · 试试

普通行 · press 中性灰底
选中行 · accent tint

按住每个元素观察:只有"终态本就是蓝"的主按钮 / 选中行在按压时见蓝;中性元素一律灰。

手势约定

  • tap主交互。命中区 ≥44,松手在区内才触发。
  • swipe-down下滑关闭底部抽屉 / 模态;顶部下拉刷新。
  • swipe-row列表行左滑露出操作(删除=danger,置顶等)。
  • edge-back左缘右滑返回上一层(导航栈)。
  • long-press唤起上下文菜单 / 进入多选 / 拖拽排序。

反馈约定

  • 视觉press 100–120ms 内即时响应(缩放/变色)。
  • 触觉关键确认(开关、删除确认、长按)配轻 haptic。
  • 异步结果用 snackbar / toast,不打断;破坏性操作用 sheet 二次确认。

60 Dogfood · 压缩机商城反哺 findings & fixes

用这套规范搭了一个完整的工业压缩机商城 App(5 Tab + 商品详情 + 规格/筛选 sheet)。真实场景压测暴露了几类问题,下面是发现与修复。

发现 & 处置

类型发现处置
App 缺陷详情页的粘底操作栏与主 Tab 栏双底栏堆叠push 屏改为覆盖整个 app-shell(含 Tab 栏),详情全屏、操作栏接管底部 ✓
App 缺陷把“筛选”动作塞进了分段控件轨道——违反自己 §33拆出为独立 outline 筛选按钮;分段只留综合/销量/价格 ✓
规范缺口缺四个通用模式:图片占位、数量步进器、粘底操作栏、空态歕业进 mobile.css(下方),成为正式 .m-* 组件 ✓
色彩体系价格需一个独立强调色——不能用 accent 蓝(非选择)也不能用 danger 红(非错误)新增领域语义色 --c-price(借桌面 refinery 安全橙);与三色语义分离
规范补充push 屏导航起/落点、覆盖 Tab 栏的层叠模型未文档化补入本节「层叠铁律」 ✓
层叠铁律带粘底操作栏的 push 屏(商品详情)必须覆盖主 Tab 栏——否则两条底栏堆叠。做法:Tab 栏与 push 屏同属一个 .app-shell(relative 容器),push 用 position:absolute; inset:0; z-index:40 盖住整个 shell。状态栏与手势条在 shell 外,始终可见。
