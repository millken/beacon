components / cmdp

Command Palette

.cmdp 是 ⌘K 风格的命令面板：容器表面沿用浮层契约（--popover / --shadow-pop / --dialog-radius），宽度与列表高度经 §4 参考旋钮 --cmdp-w / --cmdp-list-h 驱动；item 高度与内边距复用 menu 旋钮 --menu-item-h / --menu-pad（同一套「行高节奏」跨组件保持一致）；当前高亮行经接线 --subtle / --subtle-foreground，比 menu 的实色 hover 更克制——命令面板停留时间短，不需要抢眼的强反色。
