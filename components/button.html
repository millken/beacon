// components · button

Button

扁平设计:实色填充 + 1px 边框,不用高光 / 斜面 / 投影。层级只靠填充色 + 边框 + 文字色表达 —— Primary 实色 accent、Default 中性面、Ghost 无边框。交互态仅切换表面色,简洁克制。所有取值引用 token,light / dark 一键换肤。

Variants
Default → bg-surface + 1px border · Primary → 实色 --primary + 同色边框 · Danger → 实色 --destructive
Ghost → 透明,hover 才出现 bg-hover,无边框无投影 · Outline → 透明 + border-strong,次强调 · Disabled → opacity .45
Sizes
sm pad 3/9 · 12px · h≈24 — 工具栏 / 表格内  |  md pad 5/13 · 12px · h≈28 — 默认  |  lg pad 7/16 · 13px · h≈34 — Hero / 对话框
States · rest / hover / pressed / focus / checked
hover → bg-hover + border-strong  |  pressed → bg-active + 顶边内凹 inset(footprint 不变,不位移)
focus → border = primary + --focus-ring(键盘可见)  |  checked → 实色 accent 填充(toggle 选中态)
Icon · prefix / suffix / icon-only / loading
Prefix & suffix icon
Icon-only · 22 / 26 / 32
Loading · width holds steady, label dims
图标 14px(sm 12 / lg 16),stroke 1.6,随 currentColor。前后缀图标 opacity .7 让文字主导。
icon-only 正方形 22 / 26 / 32。loading 时 spinner 取代图标、label 变暗、宽度保持不变(防止抖动)。
