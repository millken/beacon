components / buttons

Buttons

Variants

六种变体只切换 .btn 私有接线 token（--btn-bg/-fg/-border(+hover/active)），root 的结构、圆角、阴影一律不变。

Sizes

sm/md/lg 三档只调 height + padding + font-size，引用 --control-h-* / --control-pad-*-* Tier-3a 控件解剖层。

Icon-only

.btn--icon 把 width 收窄到 --control-h-*（正方形），可叠加任意变体与尺寸。

Loading

data-loading="true" 时 spinner 取代图标、label 变暗（color-mix），宽度保持不变，防止抖动。

Disabled

:disabled 统一降为 opacity .55，不改变接线 token，不再逐变体定制禁用配色。

--btn-radius: 0px

容器级 style="--btn-radius: 0px" / style="--btn-shadow: var(--shadow-card)" 局部覆盖 §4 结构旋钮，无需改 .btn 任何声明——证明皮肤覆盖（skin override）生效。
