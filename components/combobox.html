Combobox

.combobox 是「输入 + 弹出 .listbox」的复合控件：输入井外观与 .input 同构（--color-input-bg / --input / --shadow-inset），但通过自身接线读取，不引用 field.css 的私有 --field-bg / --field-border（field 契约仅供 .input/.select/.token-input 内部改写，跨组件消费会耦合两族的变体切换）。.listbox 复用 menu 的 §4 旋钮 --menu-min-w / --menu-pad / --menu-item-h，表面沿用浮层契约（--popover / --shadow-pop）；hover 用 --subtle，已选中项用 --color-primary-light-default + --color-primary（比 hover 更持久的「勾选态」提示）。

闭合状态

.combobox（闭合）

未展开时插入符（caret）为 --color-text-dim；展开态（下节）经 .combobox[data-open] 转 --color-text，与选中态无关，只反映「当前是否展开」。

禁用状态

.combobox[aria-disabled]

禁用态整体 opacity 降低并禁止交互（cursor: not-allowed 由 disabled 属性的用户代理默认行为处理），与 field.css 的 .input[disabled] 视觉语言一致，但通过 combobox 自身样式表达，不跨组件借用 --field-* 接线。
