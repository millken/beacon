规范速览

两级契约：colors_and_type.css 提供 Tier-1/2 色盘与角色 + Tier-3a 共享控件解剖层（--control-h-* / --control-pad-* / --control-radius …）与 §4 结构旋钮注册表；每个 components/css/<组件>.css 只声明 Tier-3b 组件私有接线 token（variant API，写在根选择器）并引用 §4 旋钮（skin API，只在引用位出现）——不得混用两种写法。

  1. R1 禁字面量：组件 CSS 不得出现十六进制色值或 rgb()/rgba()（transparent/currentColor 除外），一律引用 token。
  2. R2 引用边界：组件 CSS 只能引用自身接线 token、§4 结构旋钮、Tier-3a、Tier-2，禁止引用其他组件的私有接线 token。
  3. R3 声明位铁律：§4 注册的结构旋钮只允许在 var(--旋钮) 引用位出现，绝不能在任何组件选择器里重新声明（会屏蔽全局/容器覆盖）。
  4. R4 前景配对：使用表面角色（--primary / --destructive 等）背景时必须配对其 -foreground，保证可读对比度。

校验：tools/check-tokens.sh 无参数 = 全量扫描 components/css/*.css，也可传入单个/多个文件路径做局部检查；退出码 0 = 零违例。

tools/check-tokens.sh; echo "exit=$?" # 全量校验，期望 0 error(s), exit=0 tools/check-tokens.sh components/css/table.css # 只查一个文件
