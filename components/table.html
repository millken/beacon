Table

表格分两类，设计语言刻意区分，避免一套样式硬套两种场景。.table 服务于「记录」——条目可读、信息丰富（头像 / 副行 / 操作），密度适中，行选 = 前导复选框；.datagrid 服务于「遥测」——纯数据高速扫读，mono 等宽数值、行号索引轨、可排序 / 调宽 / 重排的表头、底部 LED 状态栏。判断口诀：要读的用 table，要扫的用 datagrid。
