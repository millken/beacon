Tables

表格分两类,设计语言刻意区分,避免一套样式硬套两种场景。Standard 服务于「记录」——条目可读、信息丰富(头像 / 副行 / 操作),密度适中;Data 服务于「遥测」——纯数据高速扫读,mono 等宽数值、行号索引轨、可排序 / 调宽 / 重排的表头、底部 LED 状态栏。判断口诀:要读的用 Standard,要扫的用 Data。

Standard .tbl

记录 / 列表 / 设置项。每行是一个「东西」,人需要逐行阅读、识别、操作它。

  • 字体sans 正文 13px,可读优先
  • 密度松(行高 ≈ 38px),留白舒展
  • 表头填充条 · 句首大小写 · 静态
  • 选择前导复选框 + 全选
  • 单元头像 / 副行 / 徽标 / 行内操作
  • 底栏分页(1–8 of 24)

Data .dt

遥测 / 队列 / 监控。每行是一条数据,人成批扫读、排序、对比数值。一屏 30+ 行常态。

  • 字体mono + tabular-nums 数值列
  • 密度紧(行高 ≈ 26px),信息满载
  • 表头裸底 · 全大写 mono · 强底边
  • 选择整行点击 + 索引轨 accent 条
  • 表头交互排序 / 拖缘调宽 / 拖拽重排
  • 底栏LED 状态遥测(4 running…)
