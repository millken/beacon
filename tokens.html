// section 00 · overview

Beacon Design Tokens

结构借鉴 Semi Design 的成熟 Token 体系——基础元素与样式解耦、功能色展开为完整交互态矩阵(默认/悬浮/激活/禁用/浅版)、文本与填充按层级语义化、一键明暗切换;色盘与调性取自团队现行的 Beacon 桌面级系统——高密度、硬边、低彩中性基底、mono 优先、状态色服务于读取而非装饰、半径上限 6px。两者合一:Semi 的骨架,Beacon 的皮肤。

DO · 借 Semi 的结构
每个语义色都展开 默认 / 悬浮 / 激活 / 禁用 + 浅版三态;文本分四级;一处变量驱动全站 + 一键换肤。
DO · 用 Beacon 的调性
紧凑信息密度、正文 13px、1px 实线分隔、mono 数值、状态优先。对标 VS Code / JetBrains / DaVinci。
DON'T · 不模仿 iOS
大圆角、毛玻璃、超大留白、模糊阴影都不属于工业桌面。半径上限 6px(单旋钮 --radius),阴影只为弹层服务。
DON'T · 不堆装饰
不用渐变背景、装饰插画、emoji 状态。LED 圆点 + 等宽数字 + 1px 描边足以承担一切语义。

注:色盘默认采用 Beacon · radix-blue。presets.js 另含 14 套场景化 preset(Chrome / Antd / Console / Studio …),本规范聚焦体系结构,preset 为可选扩展。

01表面层级6-step surface

从最底的编辑区到反相浮层,六级背景构成层级骨架。暗色下用背景而非阴影区分前后;浅色采用平面模型(抬升容器共用内容平面,靠 shadow + 强描边抬升)。

--color-bg→ <body> / 编辑区
--color-bg-subtle→ 侧栏 / toolbar / 表头
--color-bg-surface→ 卡片 / 面板 / 按钮 / 输入
--color-bg-hover→ hover 态
--color-bg-active→ selected / pressed
--color-bg-inverse→ tooltip / toast(反相)

02文本4-step · 对齐 Semi text-0..3

四级文本按对比度目标分层:主要 ≥ 7:1、次要 ≥ 4.5:1、辅助 ≥ 3:1、text-3 最弱(占位符/禁用)。命名同时提供 Beacon(text / text-muted / text-dim)与 Semi(text-0..3)两套别名。纠正:--color-text-3 曾误借用 --color-text-inverse 的值,已改为从 --color-text-dim 淡出派生的独立弱化阶;--color-text-inverse 单独用于反相浮层(tooltip/toast),不属于本页四级淡出序列,见上「01 表面层级」的 --color-bg-inverse 一行。

05语义角色shadcn-style roles

在色盘之上再抽象一层语义角色:每个表面 role 都与 -foreground 配对,保证其上文字永远合法。组件优先引用 role(如 --primary / --card / --muted / --destructive)而非裸色阶。该层在所有 preset × 明暗间静态映射。

10图表色板dataviz · preset-independent

面向图表数据序列的分类调色板 --chart-1..6，经色盲 + 正常视觉可分辨性验证后采用；最初复用 accent/success/warning/danger 作为图表色系的方案未通过验证（可分辨性不足），故改用这组独立的固定值。有意与 14 套 preset 无关——图表色不随换肤变化，仅明暗主题各有一版；只用于图表数据标记本身，UI chrome 仍消费纯 Beacon token。

token预览用途
--chart-1..6 blue / green / magenta / yellow / aqua / orange · 分类序列（dataviz 已验证）
--chart-grid图表网格线（= --color-divider）
--chart-axis坐标轴 / 刻度文字（= --color-text-dim）
